# GC Stats Documentation

Welcome! This site explains how to use GC Stats, whether you manage an organization or build something on top of its data.

## Who this is for

- **Organization staff** — use the [Dashboard](/dashboard/overview) to manage your organization's profile, members, dashboard access, news, production credits, stream channels, and VODs.
- **Developers** — use the [API](/api/overview) to pull player and team data into your own tools.

## Where to start

- New to the Dashboard? Start with [Dashboard → Getting started](/dashboard/overview).
- Integrating the API? Start with [API → Overview](/api/overview).
