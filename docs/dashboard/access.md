# Access

:::info
**Access** controls which accounts can actually **log in** to your organization's Dashboard, and with what role. It's not your public credit list — for that, see [Members](/dashboard/members).
:::

This page shows one card per account with access, including their avatar, username, and the roles they can be assigned (you can combine several non-owner roles on the same account). "Owner" is a separate status, not a custom role.

Email addresses are never shown anywhere in the Dashboard.

## What you can do here

- **Grant access** to a new account (search by username or email)
- **Edit** the roles of an existing account
- **Revoke** an account's access

:::tip
If you don't see any roles to assign yet, create one first on the [Roles & permissions](/dashboard/roles-permissions) page — you need at least one custom role before you can grant non-owner access.
:::

## Rules

- Only an **existing owner** can grant, change, or revoke another owner's access.
- A non-owner with the **Manage access** permission can only manage non-owner accounts.
- An organization must always keep at least one owner.

See also [Roles & permissions](/dashboard/roles-permissions) to define what each custom role can do.
