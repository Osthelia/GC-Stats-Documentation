# Stream channels & VODs

## Stream channels

You need the **View streams** permission to see this page; without it, it's shown read-only.

Two panels:

- **Channels** — name, platform, URL, language, active status. Adding/editing requires **Edit streams**; removing requires **Delete streams**.
- **Links** — connects a channel to specific matches within a tournament (requires **Link streams**). A filterable, paginated list shows every channel-to-match link, with an "unlink" action. By default, it's filtered to upcoming matches.

## VODs

A list of VODs (URL + language), each attached to a tournament or match, scoped to either the "whole match" or a "specific map". Adding, editing, or removing a VOD requires **Link VODs**. By default, this list is filtered to past matches.
