# Documentation GC Stats

Bienvenue ! Ce site explique comment utiliser GC Stats, que vous gériez une organisation ou que vous développiez quelque chose à partir de ses données.

## À qui s'adresse ce site

- **Le personnel d'une organisation** — utilisez le [Dashboard](/dashboard/overview) pour gérer le profil de votre organisation, ses membres, l'accès au dashboard, les actualités, les crédits de production, les chaînes de stream et les VODs.
- **Les développeurs** — utilisez l'[API](/api/overview) pour récupérer les données des joueurs et des équipes dans vos propres outils.

## Par où commencer

- Nouveau sur le Dashboard ? Commencez par [Dashboard → Prise en main](/dashboard/overview).
- Vous intégrez l'API ? Commencez par [API → Aperçu](/api/overview).
