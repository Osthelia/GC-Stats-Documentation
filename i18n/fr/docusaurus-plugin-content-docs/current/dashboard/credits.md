# Crédits de production

Cette page recense qui a casté, produit ou organisé un tournoi ou un match pour le compte de votre organisation — elle est affichée sur la page du tournoi ou du match concerné. Ne la confondez pas avec votre liste de membres publique ; voir [Membres](/dashboard/members) pour cela.

Chaque carte de crédit affiche :

- la personne
- ce à quoi elle s'applique : un tournoi entier, ou un match spécifique
- son rôle : Caster, Analyste, Host, Observateur, Organisateur, Producteur, Éditeur, Photographe, Traducteur, Arbitre, ou un champ libre « Autre »
- un titre d'affichage optionnel qui remplace le rôle lorsqu'il est montré publiquement (ex. « Analyste invité »)

Ajouter, modifier ou supprimer un crédit nécessite la permission **Gérer le staff**.
