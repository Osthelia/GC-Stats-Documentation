# Profil de l'organisation

La page **Profil** contrôle l'apparence de votre organisation sur l'ensemble de GC Stats.

## Informations générales

- Nom et slug (l'identifiant utilisé dans les URLs de votre organisation)
- Pays principal et secondaire
- Liens sociaux : X/Twitter, Twitch, Instagram, YouTube, TikTok, Discord
- Tags (badges activables affichés sur votre profil public)

Nécessite la permission **Modifier le profil de l'organisation** (`organization.profile.edit`).

## Logos

Un panneau séparé vous permet d'ajouter, remplacer ou supprimer les logos de votre organisation :

- logo pour le thème clair
- logo pour le thème sombre
- logo neutre

Téléversez une image carrée de 10 Mo ou moins — les images carrées fonctionnent le mieux. Nécessite la permission **Téléverser/gérer les logos** (`organization.logo.upload`).

## Si vous ne pouvez pas modifier

Si vous n'avez pas les permissions requises, la page reste visible mais passe en lecture seule : vous verrez une notice expliquant pourquoi, ainsi qu'un résumé simplifié du profil à la place du formulaire de modification.
