# Chaînes de stream et VODs

## Chaînes de stream

Vous avez besoin de la permission **Voir les streams** pour voir cette page ; sans elle, elle est affichée en lecture seule.

Deux panneaux :

- **Chaînes** — nom, plateforme, URL, langue, statut actif. Ajouter/modifier nécessite **Modifier les streams** ; supprimer nécessite **Supprimer les streams**.
- **Liens** — relie une chaîne à des matchs spécifiques au sein d'un tournoi (nécessite **Lier les streams**). Une liste filtrable et paginée affiche chaque lien chaîne-match, avec une action « délier ». Par défaut, elle est filtrée sur les matchs à venir.

## VODs

Une liste de VODs (URL + langue), chacune rattachée à un tournoi ou un match, avec une portée « match entier » ou « carte spécifique ». Ajouter, modifier ou supprimer une VOD nécessite **Lier les VODs**. Par défaut, cette liste est filtrée sur les matchs passés.
